# 口袋待办 v1.2 开发中

v1.2 尚无可交付 APK。当前是 JVM 领域规则与文件边界阶段，不是完整 Android 产品。

已发布 v1.1 预览仍可从 [原发布页](https://github.com/supercubegame/todo-pocket-android/releases/tag/preview-35575804413-1) 获取。旧包、main 与 PR #3 保持原样，本分支不提供覆盖升级承诺。

## 已实现范围

活动分类/应用关联、自定义字段、精确金额账本、打卡日历、有序图文引用的领域模块；旧备份普通待办预览；按内容摘要保存文件、失败清理和重复文件校验；版本化 ZIP 传输容器，校验清单、精确文件集合、摘要、展开预算，读入全新暂存目录。

文件保存不等于已验证图片可解码。传输容器的 state.bin 仍是待数据库适配器解释的数据，不等于完整数据库恢复。LegacyImport 尚未写入数据库，不能宣称已迁移。

## 验证

固定命令：`python3 tools/verify.py v12`，需要真实 JDK 17。运行旧核心、领域规则与生成的 Java 文件边界测试，使用全新编译目录。文件测试运行真实临时文件读写和 ZIP 操作，不是 Python 模拟产品逻辑。

先行提交 78c882d55b328f8e48a82d907e27cfced3a7e2f0 / 35611212832 在旧 54 项和领域 82 项通过后，因缺少 LegacyImport 实际失败。实现提交 c651fa379ebbdcb91e076d36024b49b343082e5d / 35611413797 初轮文件 40 项通过；其中中断输入夹具随后收紧为精确异常身份，避免大小预算造成错误绿灯。以最新 SHA 对应 evidence 报告为准，不继承上一提交结果。

流水线只含核心和报告任务，明确 `release_ready=false`。`python3 tools/verify.py build` 故意失败，且 CI 实测阻断原因，防止将继承的 v1.1 UI 冒充 v1.2。

## 待完成的一半

真正 Android 数据库及事务/恢复、完整活动路径/标签/计划/模板/搜索、原生 Today/Activities/Calendar/NoteEditor 界面、图片选择与可解码性/缩略图/裁剪遮挡、PDF/分段图片/Markdown+assets 导出、完整数据库媒体恢复和旧版事务导入、独立包构建/lint/模拟器/真机验收。

Android 8 上的 Java 集合和 NIO API、硬链接发布、系统选择器以及真实大图仍需实测。文件内容已请求同步不意味着验证了断电耐久性。备份元数据/状态的 8 MiB 上限是暂定内存防护，不是设备容量测量结果；媒体逐文件/总展开预算由调用方显式提供。

## 安全边界

目标独立包 `com.supercubegame.pockettodo.v12.preview`，1.2/code3，尚未构建。保留旧版，不自动读取旧应用私有数据。备份不加密，摘要不证明作者身份。分享默认排除私有内容，真正遮挡必须改变导出字节，不能把原图混入分享包。暂不提供云同步、自动打卡或付费服务。

长期签名需用户在可信本地生成备份并配置，私钥不得进入聊天、源代码或日志。一次性 debug 包不是长期升级通道。
