# 口袋待办 / Pocket Todo 1.1 预览版

原生 Android 离线 Todo：新增、完成/取消完成、筛选、确认删除、编辑、本地保存、文件备份导出、导入预览与单次撤销。无账户、联网权限、遥测或第三方运行时库。

## 保护旧版数据

旧版包名 `com.supercubegame.pockettodo` 保持不动。旧版没有文件导出功能，也无法用新签名覆盖安装；不要为安装新版而卸载旧版。

本轮仅提供 `PocketTodo-1.1-preview.apk`，包名 `com.supercubegame.pockettodo.safe.preview`，显示名“口袋待办·预览”，与旧版并存。它不会读取或自动迁移旧版私有数据。预览版使用一次性 debug 签名，不是持续升级渠道；请只使用测试数据，更新预览版前先导出备份。

未来稳定包名预留为 `com.supercubegame.pockettodo.safe`，不会与预览包冲突；长期签名尚未配置，不交付正式版、不声称完成升级验证。用户需在可信本地环境生成并离线备份密钥，再通过仓库 Secrets 配置；不得把私钥、口令或密钥文件发到聊天、源码、公开附件或日志。旧版临时签名不可恢复，新密钥不能让旧安装原地升级。

## 安装和操作

Android 8.0 及以上。从 Releases 下载经过完整闸门的预览 APK，只临时允许下载来源安装未知应用。旧版继续保留。

点击行内“改”编辑标题，完成状态、ID、排序保持不变。最多 500 条，每条最多 200 个 UTF-16 代码单元。

“导出备份”导出全部待办，不受筛选影响。通过系统文件选择器选择可信位置；写完后重新读取并逐字节校验才显示成功。文件未加密，选择云盘提供程序可能导致该提供程序同步文件，应用自身不联网。导出失败时可能留下不完整文件，不要使用该文件。

“导入备份”先验证格式、版本、大小、校验和及全部数据，再显示数量预览；确认替换才写入。空列表备份是有效备份，确认后也会替换当前列表。取消或无效文件不修改列表。导入前列表与新列表在同一 SharedPreferences 提交中保存，可用“撤销导入”恢复，重启后仍可撤销。只保留最近一次导入前快照，后续新增、编辑、勾选或删除会取消撤销机会，不是多级历史。

备份格式：ASCII `POCKET_TODO_BACKUP`、版本 `1`、小写 SHA-256、规范 Base64 的存储 v1 载荷，各自占一行，文件以换行结束；上限 1,000,256 字节。SHA-256 仅检测损坏，不证明来源可信。跨预览与未来稳定包的备份格式可复用，但这不等于已完成稳定版升级测试。

本地数据损坏时保留原始内容，禁止修改、导出和导入，不静默重置。备份 I/O 在工作线程执行；没有持久后台导出任务，操作时建议保持应用前台，不要旋转或强制停止。

## 构建与验收

JDK 17、Gradle 8.9、AGP 8.7.3、Android SDK 35 / build-tools 35.0.0。先 `python3 tools/verify.py core`，再 `python3 tools/verify.py build`。`tools/emulator_gate.py` 只用于一次性 CI 模拟器，会运行 `tools/ui_test.py`，不要连接真实手机运行清空数据的测试脚本。

核心闸门保留 v1.0 的 26 项检查并增加编辑、备份版本/校验/边界/损坏拒绝等检查。模拟器测试操作真实 APK 和系统文件选择器，验证编辑、导出回读、取消、导入替换、撤销、重启持久化，以及原版 APK 同机并存且测试数据不变。截图来自实际运行，不是效果图。

CI 在全部行为闸门通过后才发布预览 Release。报告位于 evidence 分支 `reports/<source-SHA>-<run-ID>.json`，保留失败日志和真实结果，并逐字节读回。失败结果不覆盖旧版 Release。

尚未验收：v1.1 真机、长期签名及跨版本覆盖安装、云盘文件提供程序、磁盘写满等故障注入、I/O 中旋转/进程被杀、字体放大及厂商差异。v1.0 的 realme GT 5G 好评只属于当时的 APK，不能替代 v1.1 验收。本轮不合并主干，不修改旧版 APK。
