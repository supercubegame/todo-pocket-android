## 本轮：受保护恢复后台与备份页确认界面

AppDatabase.prepareRestore 与 confirmRestore：完整验证 ZIP、schema2 状态、关联和媒体后，冻结私有暂存快照；返回不可改的当前/待恢复18表数量。预览不替换本机数据，不发布媒体。调用方必须展示替换影响、获得明确同意，再确认；取消或放弃页面必须 close 计划。

计划绑定数据库 helper 实例及会话，只能尝试确认一次；取消、失败、成功后重试都要重新预览。helper close 后失效，但未自动清理遗弃计划，生命周期/崩溃清理待 UI 接入。源文件在预览后被替换不会偷换已审核内容；确认读取冻结副本。确认还会重新校验暂存媒体摘要，损坏即拒绝。

过期保护比对完整规范状态（含修订号），不只比一个版本数字。提前检查用于减少无用媒体复制，最终比对必须与全部记录替换在同一个写事务，防止检查与写入之间丢更新。普通写入、另一个连接不更新修订号但改内容，也应拒绝旧预览；真正幂等无变化重试不应误判过期。完整媒体复制与暂存清理在事务提交前完成。

备份页界面接通真实系统文件选择器：选择备份后冻结预览并逐表显示「当前/恢复后」数量，只有点「确认替换」才替换本机数据；「取消恢复」不动数据并可见提示。预览后任何待办或弹窗写入会让确认按钮失效并提示重新预览（其他界面的写入仍由确认前的完整状态守卫兜底，可能不即时禁用按钮）。损坏备份经同一选择器只报错、不动本机数据。界面只走 prepareRestore/confirmRestore，不使用绕过预览的旧 restoreBackup。

**撤销恢复仍未实现。** 遗弃计划的崩溃清理、预览排队期间写入的即时禁用（后端守卫仍拒绝其确认）、确定性竞争注入未专项验证。设备测试新增预览无副作用、独立数量、不可改摘要、取消、来源绑定、过期保留、同修订号内容变化、暂存媒体损坏、准确后置故障回滚、源文件替换、成功/失败重放拒绝、幂等无变化及独立进程重开；原生门另走真实选择器预览、取消、写入失效、显式替换、重启保留与损坏拒绝。报告读取完整阶段输出并逐项核对必需检查，不依赖截断日志尾；解析器另有正负自测。索引 reports/restore-plan-<SHA>-<run>.json 标识后端覆盖，SAF 界面覆盖以原生索引为准，回写后末尾作业对两者缺失都判红。

## 数据、备份和媒体边界

原生 Java、SQLiteOpenHelper schema2、FK/WAL/事务。活动、应用、路径/标签、分精度账本及重试/撤销日志、打卡日期与录入时间、有序私有/公开图文块、媒体登记、八类字段及字段笔记、独立普通待办。稳定身份，字段归档保留历史并拒绝新值/新关联。新数据不继承旧500条/200字配额，但资源有限，不承诺物理无限；列表与汇总全量加载。

旧Todo备份单独验证后事务追加，以来源摘要和映射ID防同文件重复，改变内容的备份可能追加语义相似项；不会发明活动/打卡/钱。导入 UI/撤销未做。schema1到2仅新增表迁移，冻结旧DDL夹具只覆盖部分旧数据，并非所有升级异常。旧 TodoModel/BackupCodec/CoreTest 不动。

全备份固定18表/列/类型、严格UTF8/长度/尾随校验，未知表拒绝以免漏备份；可信DDL临时库验证外键、字段（含归档值）、日期、顺序和账本日志，不执行备份SQL。快照保留ID、排序、私有内容、修订和批次/导入日志。完整备份包含私有内容且未加密，不能当分享包；摘要不是来源认证。

媒体集合/大小/摘要必须匹配；不可变内容ID私有复制用锁和原子移动，不删除原相册。恢复是替换，不是合并；失败保留旧DB/媒体，但可能留下新孤立字节（含确认时发现暂存损坏的情况），不可盲删，安全GC待做。暂存清理先于提交，数据库内规范读回。8MiB状态/清单预算是暂定内存保护，不是容量实测。断电、磁盘写满、跨进程压力、真实照片解码、SAF导出/云盘均非已验收能力。

旧设备夹具保持18表非空、独立编码器、真实ZIP和合成媒体、合法ZIP中的语义损坏拒绝、精确触发器后置故障及整库回滚、重复恢复、重启后日志可用。原158项保留，恢复计划后台22项与恢复界面检查是增量；合成字节不等于真实图片。
